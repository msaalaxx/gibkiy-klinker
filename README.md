# Гибкий клинкер — Flask-сайт

## Запуск в PyCharm
1. File → Open → выберите эту папку, создайте виртуальное окружение (venv).
2. В терминале PyCharm: `pip install -r requirements.txt`
3. Запустите `app.py` и откройте http://127.0.0.1:5000

## Публикация на GitHub Pages + домен gibkiyclinker.ru
1. `python freeze.py` — соберёт готовый сайт в папку `docs/` (внутри уже есть CNAME).
2. Закоммитьте и отправьте всё на GitHub (Git → Commit → Push).
3. GitHub → Settings → Pages → Branch: `main`, папка `/docs`, Custom domain: `gibkiyclinker.ru`.
4. У регистратора домена: 4 A-записи для `@` — 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153; CNAME для `www` → `ваш-логин.github.io`.
5. Когда DNS обновится, включите «Enforce HTTPS».

После любых правок кода повторяйте `python freeze.py` и пуш.

## Отзывы (без базы данных)
- Страница `/reviews/`, кнопка «Оставить отзыв» открывает окно: ФИО, оценка 1–10 (⭐), текст до 221 символа (`REVIEW_MAX_LEN` в `app.py`, можно поставить 155).
- Отзыв посетителя сохраняется только в его браузере (localStorage), другие посетители его не увидят.
- После отправки сайт предлагает переслать отзыв вам в WhatsApp. Чтобы отзыв увидели все, добавьте его в список `REVIEWS` в `app.py`, затем `python freeze.py` и push на GitHub.
